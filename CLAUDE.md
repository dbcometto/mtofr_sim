# CLAUDE Instructions

MTOFR_SIM: a simulator for platform-agnostic mission-type orders for robots (pure Python).


## Run
Run with `.venv\Scripts\python.exe main.py`; test with `.venv\Scripts\python.exe -m unittest discover -s tests`.  Current status is at the top of the roadmap below.
